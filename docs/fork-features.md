# 本 fork 的新增功能与定制

本文按时间倒序记录 [ZytriuNks/t3code](https://github.com/ZytriuNks/t3code) 自行开发的功能、定制和用户可感知的修复。

- 核对日期：2026-10-25。
- 源码基准：[数据库历史压缩修复 PR #34](https://github.com/ZytriuNks/t3code/pull/34) 对应的 fork 源码，基于 [v0.1.2 主用基线 `5e606538b9`](https://github.com/ZytriuNks/t3code/commit/5e606538b9c7)。合入状态以 PR 为准；以下不代表已安装应用已更新。
- 收录范围：只记录 fork 自身的增量。同步上游主分支或开发分支得到的功能不列入，包括 Orchestration V2、Pi 原生接入、ACP Registry、Cursor SDK、定时任务、线程交接及其配套能力；若 fork 对它们另作改进，只记录这部分改进。
- 日期口径：标题日期为功能或改进合入 fork `main` 的日期，依据主线合并记录、squash 提交或直接提交的北京时间核对；同日按合入顺序倒排。条目中的“新增日期”指首次写入本文的日期，与功能合入日期分开。
- 安装包范围：以下记录说明源码已包含的功能；具体安装包是否包含，取决于其源码提交。Web、桌面和原生移动端分别标注。

## 2026-10-25｜压缩对话条目的重复中间状态

新增日期：2026-10-25。类型：存储改进。合入状态：[PR #34](https://github.com/ZytriuNks/t3code/pull/34)。适用：所有连接该服务端的 Web、桌面和原生移动端客户端。

后台数据库维护及离线 `doctor --fix` 整理数据库时，也会清理非子代理对话条目的重复中间更新，保留每个条目最早和最新的事件，以维持重放顺序及最终状态。子代理条目保留原有事件，避免破坏提示词引用。

这项改进减少重复历史的存储增长，不限制有效历史和单条命令输出的大小，也不自动清理已删除线程的数据。现有数据库是否归还空闲空间仍取决于其自动收缩设置及离线整理情况。

来源：[PR #34](https://github.com/ZytriuNks/t3code/pull/34)，fork 独立改进；扩展上游既有压缩规则，不将原有维护能力计作新增。

## 2026-10-24｜从只读子代理会话新建续接草稿

新增日期：2026-10-24。类型：会话操作增强。适用：Web、桌面、原生移动端。

从子代理会话的 **Continue in new thread** 入口创建独立普通对话草稿，并附带源线程引用。原生子代理会话保持只读，已有未发送草稿不会被替换。

新草稿不继承原生供应商会话，不自动发送或调用供应商；用户须补充消息后自行发送，目标供应商如何使用线程引用仍取决于其支持能力。详见[线程使用指南](./user/thread-sidebar.md)。

来源：[v0.1.0 同步提交](https://github.com/ZytriuNks/t3code/commit/b64fa2c5b23d9fb764df141076a3d98b1b97b799) 中的 fork 独立续接操作；不将上游已有的原生子代理或线程交接能力计作新增。

## 2026-10-22｜对话结构与活动提示

新增日期：2026-10-23。类型：新增与定制。适用：Web、桌面。

在 **设置 → 通用 → 对话结构** 中选择“现有布局”或“重制”。重制布局将当前活动提示与历史正文分开：工具调用完成后归入正文，活动提示只显示当前思考、运行中的工具或工具后的等待状态，并随对话末尾定位。

可以分别自定义 **Thinking 文案**与**工具后等待文案**；留空使用当前界面语言的默认文案。工具失败时不会显示成正常等待。

来源：[对话与流式输出改进](https://github.com/ZytriuNks/t3code/commit/fd739b1b59)。

## 2026-10-22｜平滑流式输出与 Markdown 阅读

新增日期：2026-10-23。类型：新增与定制。适用：Web、桌面。

选择重制对话结构后，将 **响应流式传输**设为**平滑输出**，可调整：

- 输出粒度：逐字符、逐 token 增量块或自动切换，速度随输出与缓存情况调整。
- 行输出动画：动态衔接或多行并行。
- 文字淡入与新行让位时长；淡入设为 0 时关闭。
- Markdown 格式预加载，在语法和图片引用稳定前继续显示周围正文。

代码高亮、图片尺寸变化、链接图标和滚动跟随也与文字播放协调。阅读历史时保留位置，在对话末尾时跟随新内容。平滑输出仅用于重制布局，切回现有布局会回退为实时输出；其他既有流式模式不计作 fork 新增。

来源：[对话与流式输出改进](https://github.com/ZytriuNks/t3code/commit/fd739b1b59)。

## 2026-10-22｜脚注自动折叠

新增日期：2026-10-23。类型：新增。适用：Web、桌面。

在 **设置 → 通用 → 对话结构** 中单独启用脚注自动折叠。输出中的脚注展开，完成后自动收起；连续输出的脚注会一起收起。点击正文引用可展开脚注。

来源：[对话与流式输出改进](https://github.com/ZytriuNks/t3code/commit/fd739b1b59)。

## 2026-10-07｜旧版侧栏分区与草稿

新增日期：2026-10-23。类型：定制。适用：Web、桌面。

旧版侧栏按**置顶、项目、未分配**组织对话。置顶线程集中展示，无项目对话归入未分配区块；项目下保留当前草稿及已有用户内容的草稿。

分区可以展开或收起，线程行提供置顶操作，并为列表变化加入遵循减少动态效果偏好的过渡。这里记录的是旧版侧栏的重新组织，线程置顶等基础能力原已存在。

来源：[侧栏分区与草稿改进](https://github.com/ZytriuNks/t3code/commit/c6195b4a7f)。

## 2026-10-06｜自定义无项目对话的基础目录

新增日期：2026-10-23。类型：新增设置。适用：Web、桌面、原生移动端。

Web / 桌面入口为 **设置 → 通用 → 无项目对话基础目录**；移动端入口为 **设置 → 线程行为 → 无项目对话**。设置作用于选中的服务端环境。

支持环境机器上的绝对路径及 `~/` 路径，每个新对话获得独立子目录。留空恢复默认 scratch 目录；目录须在 Git 仓库之外，修改设置不会迁移已有文件。无项目对话本身为既有能力，本次新增的是目录配置。详见[线程使用指南](./user/thread-sidebar.md#start-without-a-project)。

来源：[PR #30](https://github.com/ZytriuNks/t3code/pull/30)。

## 2026-10-04｜对话内的子代理会话与 Agents 面板

新增日期：2026-10-23。类型：新增界面与定制。适用：Web、桌面。

从右侧面板空状态或 **+ → Agents** 查看当前线程的子代理与后台任务；聊天中的子代理条目也可以打开会话浮层。

- 显示标题、状态、供应商、模型、推理强度及已有 Fast 信息。
- 在侧面板或浮层中阅读子代理会话，查看嵌套子代理，或打开完整线程。
- 后台任务没有独立线程时查看父对话上下文，不创建虚拟线程。
- 避免重复列出同一子代理，并从新旧侧栏的普通对话列表中排除子代理线程。

嵌入会话用于阅读，原生子代理线程保持只读；新建独立续接草稿见本文对应条目，任务停止沿用既有入口。底层子代理运行与委派能力来自上游，此处新增的是查看、导航与展示方式。

来源：[PR #27](https://github.com/ZytriuNks/t3code/pull/27)。

## 维护约定

分支收尾时，核对本分支相对主用基线的独立增量，将实际新增功能或功能改进写入本文。不得将同步上游主分支或开发分支的功能重新列为 fork 新增，也不把同步后的兼容修复自动算作新功能。

条目使用 `YYYY-MM-DD｜功能名称` 标题，按功能合入日期从新到旧排序，同日按合入顺序倒排；另标 `新增日期：YYYY-MM-DD` 记录首次写入本文的北京时间日期。修订保留原新增日期，可另注更新日期。历史合入日期须有提交或合并记录依据。

尚未合并的分支条目标注“待合并”，标题暂用该功能开发完成日期；合并后核对实际内容，将标题改为合入日期、重新排序，并更新顶部源码基准和核对日期。放弃的待合并内容应移除，没有新增功能的分支无需编造条目。

每条说明用途、入口、适用端、来源和限制；标准功能的完整用法见[文档首页](./README.md)。
