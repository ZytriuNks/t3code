# 对话结构（Conversation Structure）

## 目标

让活动状态标签只展示**当前正在进行**的那一个 thinking 或工具调用，本轮所有工具调用实时归入上方正文。标签位置随滚动状态切换：滚动条在底部时固定，其余时候跟随正文末尾。

由项目级设置 `conversationStructure` 开关，默认 `default`（现有行为不变），选 `restructured` 时启用。

## 现状

`MessagesTimeline.logic.ts` 已经具备本设计所需的绝大部分机制：

- `activeToolEntries`（约 1207 行）收集当前轮次尾部的连续工具条目
- `activeWorkRow`（约 1250 行）把它们折叠成单个 `work-live` 行，只保留最新条目
- `activeWorkEntryIds`（约 1273 行）标记这些条目在正文投影中跳过（约 1355 行）
- 下一次工具开始时，上一批脱离该集合，被约 1394–1420 行的分组逻辑合并为正文 `work` 组

因此改造的核心是两点：**归档时机**，以及**标签行的渲染位置**。分组、折叠、展开逻辑不需要改动。

## 设置

新增项目级设置 `conversationStructure: "default" | "restructured"`，默认 `"default"`，并新增空闲提示文案键（默认 `Planning next move`）。

### 存放位置

Web 设置页目前是单页分区结构（共 8 个 `SettingsSection`，无选项卡机制），移动端才是分页导航。因此在「通用」页新增与「文本生成」同级的 `对话结构` 分区，而非新建选项卡。待选项卡能力具备后可再迁移。

### 控件

| 控件                                        | 可用条件                |
| ------------------------------------------- | ----------------------- |
| 对话结构：`默认` / `重制`                   | 始终可用                |
| 空闲提示文案                                | 仅 `重制`               |
| 响应流式：`整轮` / `段落` / `实时` / `平滑` | 仅 `重制`；默认不选平滑 |

**平滑为何挂在 `重制` 下**：平滑输出依赖逐字揭示与高度动画，而 `重制` 下正文在工具运行期间就持续增长。两者叠加会在同一帧内产生两套动画时序。默认模式下二者互不干扰。冲突的实际表现需在实施中确认，若未复现可放开为独立开关。

## 归档时机

- `default`：维持现状。`activeWorkEntryIds` 覆盖本轮全部尾部工具条目，直到下一次工具开始或整轮结束才释放。
- `restructured`：每个工具调用**结束即归档**。结束的条目立即脱离 `activeWorkEntryIds`，被既有分组逻辑收进正文 `work` 组；`activeWorkRow` 始终只反映仍在进行的那一个。

正文中本轮工具以折叠组承载，展开显示本轮全部工具清单。这与现有 `work` 组行为一致，无需新增 UI。

## 标签内容

标签（含展开）只渲染 `activeWorkRow` 所持的那一条：`activeWorkRow.entry` 即最新工具或 thinking 条目。

空窗期（工具结束、正文未开始）显示空闲提示文案。判定复用现有 `latestToolKeepsActivityLive`（约 1247 行）：该值为假即进入空窗。文案从设置读取。

## 标签位置

- **滚动条在底部**：标签固定，正文从其上方流过。
- **滚动条不在底部**：标签跟随正文末尾，即文档流末尾。

位置切换复用 `useSmoothScroll` 已有的追边机制。该 hook 每帧判断「视口是否仍停在自己上次钉底的位置」，能直接区分这两种状态，无需新增跟踪逻辑。

## 渲染位置

`work-live` 行不再进入虚拟列表，改由时间线容器上的固定层渲染。正文侧由既有逻辑产出行承载（`work-toggle` 折叠组头）。

LegendList 看到的行数组仍是合法的（`work-toggle` 取代 `work-live`），行高测量契约不变。

## 改动范围

| 文件                                 | 改动                                      |
| ------------------------------------ | ----------------------------------------- |
| `packages/contracts/src/settings.ts` | 新增 `conversationStructure` 与空闲文案键 |
| `MessagesTimeline.logic.ts`          | 归档时机分支；标签行改由正文承载          |
| `MessagesTimeline.tsx`               | 固定层渲染活动标签                        |
| `SettingsPanels.tsx`                 | 新增「对话结构」分区                      |
| `i18n/messages.ts`                   | 文案                                      |

不改动：工具分组与折叠逻辑、虚拟列表本身、`useSmoothScroll`、移动端聊天视图。

移动端设置页是否暴露 `conversationStructure`，由实施时按移动端现有设置模式决定。

## 风险

`work-live` 行离开虚拟列表后，行投影发生变化。LegendList 仍收到合法行数组，契约本身不变，但实施时必须重点验证**滚动条在底部时标签固定**在真实虚拟化下的表现——前几轮的滚动问题都出在这一带。

## 验证

- 单元测试覆盖：归档时机的两种分支、标签内容在两种结构下的取值、设置项按 `restructured` 条件启用/禁用
- 浏览器实测：滚动条在底部与非底部两种位置下的标签位置；标签内容随工具调用切换；本轮工具实时出现在正文中
